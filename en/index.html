01 · Foundations

What AI Actually Is

Start with the smallest useful mental model of a language model: it predicts and generates content from context. Its capabilities come from training and inference, but fluent language is not proof of factual reliability or genuine understanding.

01 / 06

Generative AI

A category of systems that generates text, images, or other content from input conditions.

02 / 06

LLM

A foundation model that learns language patterns through many parameters; it is not the same as a chat product.

03 / 06

Token

A discrete unit used when a model processes text and a common basis for usage measurement.

04 / 06

Context

The information available to the current inference, not permanent memory.

05 / 06

Prompt

The input and constraints given to a model, including system-level and user-level instructions.

06 / 06

Hallucination

Output that sounds credible but lacks factual support; verify it rather than trusting it blindly.

11 · Safe operation

Stronger Capabilities Need Closer Guardrails

Agent autonomy must come with budgets, least privilege, approvals, isolation, verification, stopping conditions, and a rollback path. Final responsibility cannot be delegated to a model.

Least privilege

Grant only the narrowest scope needed for the current task, separate read from write access, and require explicit approval for sensitive actions.

Review changes before applying them

Use dry runs, diffs, backups, and rollback so changes can be inspected and reversed.

Isolation and secrets

Isolate browser sessions, keep credentials in secret storage, and never paste them into chats or logs.

Resist injection

Instructions in webpages and files are untrusted input. They must not override the system goal or authorization boundary.

Make actions observable

Record tool calls, failures, retries, and stopping reasons so a person can review the execution.

Human review

People must confirm high-impact results. Never make YOLO mode or disabled approvals the beginner default.
